把漫画图片做成电子书

选一个装着漫画图片的文件夹，MangaBox 会自动拆页、裁掉白边、放大到阅读器的分辨率并居中，做成 EPUB / CBZ。做好的书放进书架，追更、看新刊、找新番原作，把收藏管起来。免费，双击就能用。

在阅读器上舒服地看漫画

从网上拿到的漫画图片往往是两页拼在一起的横图、留着大片白边、分辨率又不够。MangaBox 一步帮你处理好。

做书

拆

自动拆页

两页拼在一起的横图自动拆开；日漫先右后左，国漫、韩漫、欧美漫画可以选从左往右。

裁

裁掉白边

模型找出正文范围（包括出框的人物、对话框和拟声字），页码和水印不影响裁切。

放

放大与居中

放大到阅读器分辨率，全书统一大小，翻页不会忽大忽小。

名

自动认书名

从文件夹名认出书名、作者和卷号，去掉下载站标记；也可以联网到 Bangumi 查正式书名和作者。

查

检查与前后对比

模型不太确定的页排在前面，拖动红框调整；原图和成品叠在一起，拖动分界线看裁掉了什么。

套

整套与连载

多卷漫画每卷做成一本；按话发布的资源做成一本连载，一话一话往下排，新出的话随时补上。

修

画质与体积

扫描件发黄、歪斜自动修正，网站水印可以去掉；为墨水屏优化后体积更小，传到阅读器更快。

动

下载完自动做

指定下载文件夹后，书架上做过的作品出了新卷，下载完就按上次的设置自动做成书。

收藏

架

书架与分类书架

整套叠在一起，标“想读 / 在读 / 读完 / 搁置”；建“通勤”“已收齐”这样的分类书架，一部作品可以放进好几个。

主

作品主页

封面、评分、作者、出版社、标签和简介；各卷的出版时间线，有哪几卷、缺哪几卷一眼看出。

追

追更与新刊日历

出了新卷在封面上提醒；按月历看书架上的作品哪天出下一卷。

番

新番原作

当季和下季动画里有哪些漫画原作，有介绍、评分和首播日期，一键加入书架。

记

想读清单

还没有书的作品也能按名字加进书架，先记下来，以后有了再做。

云

百度网盘

做好的书一键上传到自己的百度网盘，阅读器（如 BOOX）直接从网盘读，电脑上不用全部留着。官方开放平台授权，不需要密码。

统

收藏统计

收了多少作品、卷和页，作者、出版社、标签的分布，还能生成年度回顾图片。

原图不会被修改，也不会上传到网络。
支持图片文件夹和 zip / cbz / rar / 7z 压缩包，拖进窗口就能开始。
支持 BOOX Leaf 5 / Tab Mini C / Tab Ultra C / Tab X C，Kindle / Paperwhite / Colorsoft / Scribe，Kobo Clara / Libra / Sage / Elipsa 2E；其他阅读器可以自定义屏幕分辨率。

下载

免费下载，解压或打开即可使用，不需要安装 Python 等任何环境。

macOS

Apple 芯片（M1 及更新），macOS 12 以上。

下载 .dmg
  1. 打开 dmg，把 MangaBox 拖到“应用程序”。
  2. 第一次打开时如果提示无法验证开发者，到“系统设置 → 隐私与安全性”点“仍要打开”。

Windows

64 位 Windows 10 / 11。有显卡（NVIDIA / AMD / Intel）时自动加速，不用另外安装。

下载 .zip
  1. 右键 →“全部解压缩”，打开 MangaBox 文件夹，双击“启动 MangaBox.bat”。
  2. 如果出现“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”。

常见问题

会上传我的漫画吗？

不会。所有处理都在你的电脑上完成，图片不会离开你的电脑。MangaBox 只在这些时候联网：检查新版本和下载模型（GitHub）；查找作者、追更、看作品主页和新番时向 Bangumi 查询资料（只发送作品名或条目编号）；以及你主动连接百度网盘、选择“上传到网盘”时，把你选的电子书上传到你自己网盘的“我的应用数据”文件夹。详见隐私政策。

百度网盘安全吗？

使用百度网盘官方开放平台的扫码授权，MangaBox 拿不到你的百度密码，只能读写网盘里“我的应用数据”下本应用的文件夹。令牌只存在你的电脑上，在设置里点“断开”就会删除。

为什么第一次打开会被系统拦一下？

MangaBox 是免费软件，没有购买苹果公证和 Windows 代码签名证书，系统无法验证开发者。按上面的说明放行一次即可。

做好的书在哪里？

macOS 在“文稿/MangaBox”，Windows 在“文档\MangaBox”，在“设置”里可以一键打开。

支持压缩包吗？

支持 zip / cbz / rar / 7z，可以直接选择或拖进窗口；有密码的压缩包需要先解压。

怎么更新？

有新版本时 MangaBox 会提示，在“设置 → 关于”点“更新并重启”，会自动下载、安装并重新打开（0.5.0 起），做好的书和设置都会保留。

遇到问题怎么办？

请到 GitHub Issues 反馈，并附上诊断信息：在“设置 → 遇到问题”点“导出诊断信息”，会在“下载”文件夹生成一个压缩包（不含漫画图片）。
