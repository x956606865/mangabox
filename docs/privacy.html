ACGBox 次元匣

隐私政策

更新日期：2026 年 11 月 6 日 · 适用于 ACGBox 次元匣（原 MangaBox）（macOS / Windows 桌面软件、安卓手机管理端）

本次更新：补充多设备同步（同步文件夹、WebDAV）的联网说明；百度网盘部分补充按卷替换和“高清化后替换”会覆盖你选的网盘文件；补充安卓手机管理端。

ACGBox 是一款免费的桌面软件，用来把漫画图片做成电子书、管理你的书架和番剧库。我们尽量少用网络、少碰数据：你的漫画图片和做好的电子书只在你的电脑上处理，不会上传到我们的服务器——ACGBox 没有自己的服务器，也没有账号系统。

一、我们不收集的信息

  • 不收集姓名、手机号、邮箱、设备标识等个人信息，没有注册和登录。
  • 不做使用统计、行为分析，没有广告，不接入任何统计或广告 SDK。
  • 不读取你电脑上除你选择的漫画文件夹、电子书文件夹（包括 Calibre 书库）、同步文件夹、你添加的番剧文件夹和 ACGBox 数据目录以外的文件。

二、保存在你电脑上的数据

以下数据只保存在你自己的电脑上，你可以随时删除：

  • 数据目录（默认 macOS“文稿/MangaBox”、Windows“文档\MangaBox”）：做好的电子书、制作记录、书架上的阅读状态与分类、从 Bangumi 查到的作品资料和封面缓存。
  • 用户配置目录：数据目录位置、窗口大小、“在网上查找”的网址、同步文件夹或 WebDAV 的设置（含你填写的 WebDAV 账号密码）、你填写的百度网盘应用配置和授权令牌、TMDB Key、Plex 授权令牌、AutoBangumi API 令牌、Bangumi Access Token（配置后才有，文件只允许你本人读写）。
  • 番剧文件夹：只有你使用“整理元数据”或“规范命名”时，才会在你的番剧文件夹里写入 NFO、海报等元数据文件或给视频改名；每次写入都留有记录，可以撤销，视频内容不会被修改。

四、百度网盘

  • ACGBox 通过百度网盘开放平台的官方接口和设备码授权连接你的网盘：你用百度网盘 App 扫码或在百度的网页上确认授权。ACGBox 不会获取你的百度账号密码。
  • ACGBox 使用你自己在百度网盘开放平台注册的应用（AppKey、SecretKey 由你在设置里填写），安装包里不带任何开发者的应用凭据。应用配置和授权令牌只保存在你电脑的用户配置目录（文件只允许你本人读写），不发送给我们或任何第三方。你可以把应用配置导出给你信任的人使用，导出的文件包含 SecretKey，请自行妥善保管。
  • ACGBox 只在你操作时访问网盘，且只访问你选择的位置：上传到你选的“网盘书库”文件夹（默认是“我的应用数据”下本应用的文件夹）；扫描你选的文件夹、把其中的电子书登记到书架；把你选择的书下载回电脑；在你确认整理计划后移动、改名或删除你勾选的文件（删除进入网盘回收站）；在你确认后，用本机的书或“高清化后替换”重新做的书覆盖你选的那个网盘文件（覆盖前会提醒旧文件找不回）。不分享、不公开任何文件。
  • 只有在你选择“上传到网盘”或打开“书做完后自动上传”后才会上传文件。
  • 在设置里点“断开”会删除电脑上保存的令牌；你也可以在百度账号的授权管理中撤销授权。已经上传到网盘的文件由你在百度网盘中自行管理。
  • 百度网盘对数据的处理适用百度的隐私政策。

五、诊断信息

遇到问题时，你可以在“设置 → 遇到问题”导出诊断信息。它只会生成在你电脑的“下载”文件夹里（包含日志和设置，不含漫画图片），是否发给开发者由你决定。

六、未成年人

ACGBox 不收集任何个人信息，也不面向未成年人提供特别服务。

七、政策更新

本政策更新时会在本页更新日期并说明变化；涉及新的联网用途时，会在软件的更新说明中告知。

八、联系我们
